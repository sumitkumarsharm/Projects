What is the difference between Client-Side Rendering (CSR) and Server-Side Rendering (SSR)?
Client-Side Rendering means the browser downloads a basic HTML page, and then JavaScript builds the content. This is common in React apps. Server-Side Rendering means the server creates the full HTML with content and sends it to the browser. This helps with faster page load and better SEO.
What is the difference between a component and a function ?

In React, a function is just a block of reusable code that does something, like calculations or returning a value.

A component is a special kind of function that returns JSX (UI) and is used to build the user interface of a React app.

What is a state in React ?
State is a built-in object in React that stores data or information about the component. When the state changes, the component re-renders.
What is the difference between var, let, and const in JavaScript ?

var is function-scoped and can be re-declared.

let is block-scoped and can be updated but not re-declared.

const is also block-scoped and cannot be updated or re-declared.
