# CSS Popup Project

This is a simple HTML, CSS, and JavaScript project that displays a popup section with a personal introduction and a "Sign Up" button. It also includes a styled "Subscribe us" button to trigger or accompany the popup.

## 📄 Features

- Responsive layout using CSS
- Personal introduction with styled text
- Popup-like UI design
- Custom fonts and icons using Google Fonts and Font Awesome

## 💻 Technologies Used

- HTML5
- CSS3
- JavaScript (basic interaction)
- Google Fonts
- Font Awesome

## 📁 Files

- `index.html` – Main HTML file
- `style.css` – Styling for the popup and layout
- `script.js` – Optional: JavaScript for interactions (if used)

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
