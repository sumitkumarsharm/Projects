# Newsletter Popup using JavaScript

This project is a responsive **Newsletter Popup** built using HTML, CSS, and JavaScript. It was created as a learning exercise to practice DOM manipulation, form validation, and UI interaction using vanilla JavaScript.

## ✨ Features

- 🔔 Newsletter popup with email input
- ✅ Email validation before submission
- 📩 Toastr notifications for feedback
- ❌ Close popup with a cross icon
- 📱 Fully responsive for all screen sizes
- 🎨 Modern and user-friendly UI

## 📁 Project Structure

## 🚀 How It Works

- Click on the "Subscribe Us" button to show the popup.
- Enter your email and click **Sign Up**.
- If the email is empty, an error toast is shown.
- If the email is filled, a success toast is shown and the popup closes.
- The button text updates to "Thanks For Subscribing".

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- [Toastr.js](https://codeseven.github.io/toastr/) for toast notifications
- [Font Awesome](https://fontawesome.com/) for icons
