# TODO List App

## Overview

The TODO List App is a fully responsive, drag-and-drop task management application built using HTML, CSS, and JavaScript. It allows users to create, edit, and organize their tasks efficiently. Users can also create their own spaces to categorize their tasks. This application is built using **0 APIs**, ensuring complete offline functionality.

## Features

- **Responsive Design**: Works seamlessly across all devices.
- **Drag and Drop**: Easily reorder tasks with a simple drag-and-drop interface.
- **Task Editing**: Modify task details anytime.
- **Delete**: You can delete the task if it is Done.
- **Custom Spaces**: Organize tasks into different spaces for better management.
- **User-Friendly UI**: Intuitive and easy to use.
- **Offline Support**: Works without any external API calls.

## Technologies Used

- **HTML**: Structure of the application.
- **CSS**: Styling and layout.
- **JavaScript**: Functionality and interactions.

## Usage

1. Open the application in your browser.
2. Add tasks in the task section
3. You can drag 7 drop the task when it is Completed
4. You can edit the task if you needed.
5. You can delete the task.
6. Create a new space for organizing tasks.
7. Drag and drop tasks to reorder them.
